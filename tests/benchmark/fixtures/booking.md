# Бронирование переговорных

## Лимиты

Сотрудник может создать не более одного активного бронирования в день. Администратор может создать до трёх активных бронирований в день. Роль администратора исключена из правила для сотрудников.

## API бронирования

POST /bookings создаёт бронирование и возвращает HTTP 201 с идентификатором.

GET /bookings/{id} читает бронирование и возвращает HTTP 200 с его данными.

При превышении лимита POST /bookings возвращает HTTP 409.
