# API подписки на отчёты

## Требования интерфейса

Экран при открытии читает сохранённую подписку через API. Изменения экран сохраняет через API.

## Спецификация API

Описанная операция: PUT /report-subscription заменяет сохранённую подписку.

### Ответы

Успешными считаются HTTP 200 и HTTP 201. При успешной замене подписки сервер возвращает HTTP 200. При отказе в доступе сервер возвращает HTTP 403.
