# REQ//SCAN

Откройте `index.html` в браузере. Установка и сборка не нужны.

Выберите или перетащите файл любого расширения и запустите проверку. Отчёт открывается на странице `report.html`, откуда можно вернуться к загрузке. В примере используется сохранённый прогон из `review-pdf.json`. Выбранный файл остаётся в браузере.

Для интеграции с бэкендом замените функцию `runReview(file)` в `app.js` запросом к API. Интерфейс ожидает результат с полями `document`, `model`, `requirements`, `document_findings` и `evidence`. Для паспорта прогона можно передать `run_date` и `agent_version`.
